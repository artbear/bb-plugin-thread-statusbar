# Thread Statusbar

Компактные метрики Codex и Cursor в штатной строке контекста открытого треда BB: модель, состояние, время хода, средняя скорость, токены, кеш и контекст. Определения доступны в раскрытии с клавиатуры; поля переносятся в узкой панели.

Codex использует официальный прирост output за полное время хода с подтверждённым baseline; для завершённого хода без baseline восстанавливает официальный итог того же native turn. Cursor показывает Unicode символы в секунду без перевода в токены. Неизвестные показатели обозначаются «—», оценка контекста — «≈».

Публичный SDK и собственный read-only RPC/host entry: точечно читается единственный Codex rollout нужной session на машине выполнения, возвращаются только проверенные IDs и output. Без ключей, настроек, фоновых служб и собственных команд. Отсутствующий или неподтверждённый native итог оставляет «—». BB ≥0.48, SDK 0.6.94. [Установка и формулы](README.md).
