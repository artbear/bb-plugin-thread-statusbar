# Thread Statusbar

Плагин только читает публичные события и контекст открытого треда. Для объяснения формул и ограничений прочитай [README](../../README.md#как-считаются-показатели). Чужие треды и auth/session-файлы для диагностики не нужны.

1. Установи, какой провайдер выбран: поддержаны только `codex` и `acp-cursor`. Строка принадлежит существующему треду над composer.
2. Раскрой строку кнопкой либо Tab → Enter/Space. `—` означает неизвестное значение; `≈` — оценку контекста. Отсутствующий baseline, начало хода или полный текст объясняют отсутствие скорости. Cursor измеряет символы, не токены.
3. При недоступности данных проверь состояние соединения BB. После reconnect плагин сверяет историю заново. Не делай вывод о зависании по отсутствию текста.
4. Для проверки исходников выполни `npm run check` в checkout с установленными dev dependencies и BB CLI. Для интеграции используй штатные `bb plugin list` и `bb plugin build`; управление установкой определяется поручением пользователя.

Собственных CLI-команд, RPC, настроек и записей в тред у плагина нет. Завершай диагностику указанием подтверждённого источника отсутствия данных либо конкретной непроверенной границы; не подменяй неизвестные counters оценками.
