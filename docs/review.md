# Независимое ревью

Все проверки выполнены 2026-10-30 отдельными BB-сабтредами. Первичные рецензенты и финальный integration reviewer получили новые чистые контексты без истории реализации. Они работали только на чтение; исправления выполнял отдельный исполнитель.

Первые проверки выполнены в изолированной ветке; ниже приведены эквивалентные коммиты основной ветки, куда изменения перенесены без изменения исходников.

## Спецификация

Рецензия контракта до начала кода: **ready**, блокирующих замечаний нет. Уточнены scoped events, восстановление Cursor по completed snapshot после pruning и приоритет принятой спецификации над исследовательскими вариантами.

## Standards

Первичная проверка версии 9f785cf выявила два P2: переполнение производной скорости и пропуск финального usage после completion. Повторная проверка версии 716670d подтвердила исправления и выявила соседний P2: поздний регрессирующий counter становился baseline следующего хода.

Все три закрыты. Итог на версии b35a19f: **ready**, открытых замечаний нет. Восемь независимых traces и 38 тестов подтвердили отказ от недостоверного baseline и восстановление расчёта после достоверного snapshot. Чисто стилевые эвристики не объявлялись блокерами.

## Spec

Первичная проверка версии 9f785cf выявила один P1 и два P2: late usage предыдущего хода портил baseline текущего; late usage/text своего закрытого хода не уточнял результат; totals/cache терялись без восстановленного start.

Все закрыты. Итог на версии 716670d: **ready**, новых замечаний нет. Выполнены пять исходных и 14 дополнительных assertion-сценариев, 37 тестов и typecheck. Последующая версия b35a19f дополнительно ограничила использование недостоверного baseline; в тестах проверено восстановление через свежий snapshot.

## Финальная интеграция

Третий независимый reviewer проверил интегрированный b35a19f относительно 4c42d6d без чтения истории автора: **Standards PASS, Spec PASS, общий ready**. Подтверждённых дефектов и блокеров не найдено; 38 тестов и typecheck прошли. Изменения исходников и тестов не выполнялись.

Ревью не подменяет runtime-проверки. Сборку, production-dependencies contract, установку и реальные браузерные сценарии выполнял интегратор; результаты в [validation.md](validation.md). Условность counters Cursor, неизвестный baseline Codex и ограничение 2000 событий остаются заявленными границами v1.

## Исправление завершённых ходов, 0.1.1

Новые независимые Standards и Spec ревью выполнены в отдельных чистых сабтредах относительно выпущенного `9f84b55`. Первичная реализация `97dfec7` добавила точечное восстановление официального output из native записи нужного завершённого turn через собственный read-only host RPC.

Standards выявил два P2: неполный хвост следующего native turn блокировал завершённый результат; `attempted` запоминался до фактической попытки recovery и мешал восстановлению после позднего invalid usage. Spec оценил первый дефект как P1. Обе причины исправлены в `802b40f`, добавлены регрессионные reader/observer проверки.

Повторные вердикты: **Standards READY, Spec READY**, открытых замечаний нет. Рецензенты проверили завершённый префикс при partial tail и append, сохранность session/checkpoint/reopened guards, поздний invalid/regressing usage, warm/cold равенство, существующие active/Cursor формулы и границы данных. Финальный набор — 78 тестов; живые проверки выполнялись отдельно интегратором.
